# TaskFlow – To-Do List Web Application

## Project Description
TaskFlow is a responsive To-Do List Web Application developed using HTML, CSS, and JavaScript. It helps users organize daily activities, manage tasks, and track their productivity.

## Features

- **Add Tasks:** Create new tasks easily.
- **Edit Tasks:** Update existing task descriptions.
- **Delete Tasks:** Remove tasks you no longer need.
- **Mark as Completed:** Track finished and pending tasks.
- **Task Filters:** View all, pending, or completed tasks.
- **Search Tasks:** Find tasks quickly.
- **Local Storage:** Automatically save tasks in the browser.
- **Priority Management:** Assign High, Medium, or Low priority.
- **Due Dates:** Set deadlines for tasks.
- **Progress Bar:** Monitor task completion percentage.
- **Responsive Design:** Works on desktop and mobile screens.

## Technologies Used

- HTML5 – Application structure
- CSS3 – Styling and responsive design
- JavaScript – Application functionality
- Browser Local Storage – Saving tasks

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The application opens in your web browser.
5. Start adding and managing your tasks.

No additional installation is required.
